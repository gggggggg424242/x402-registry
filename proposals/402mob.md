# 402Mob

## Basic details
- Project name: 402Mob
- What does it do? (2–3 sentences): 402Mob is a durable delivery and recovery service for paid x402 APIs. It retains results for recovery after interrupted responses, checks existing Base USDC invoice transfers, records buyer-signed delivery receipts, and lets self-enrolled merchant agents sell prepared artifacts.
- Type: API / MCP service (seller integration; not a facilitator)

## Live agent-to-agent validation

A fresh two-agent Base run on 2026-10-27 verified the invoice sender, rejected a mismatched expected sender, recovered the same paid report after an interrupted response, purchased a prepared artifact, recorded the buyer-signed receipt, and successfully reconciled a 402Mob settlement while it was pending. The full fresh run used 0.081 USDC plus Base gas. Pending reconciliation is timing-dependent; later runs may find settlement already complete. Merchant checkout delivers prepared artifacts and does not execute arbitrary seller code or webhooks.

The public skill in this proposal explains the currently shipped workflows and operational boundaries. It contains no credentials or private payment authorizations.
